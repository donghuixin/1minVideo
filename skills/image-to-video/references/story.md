# 先读图，再定镜头

输入可以只是“一组图，给初中生解释这个现象”。读图与写稿由调用 Skill 的多模态助手完成；Python 负责整理图像、布局、定时和编码，不会从文件名猜主题。没有独立语音引擎也可完整输出画面、字幕和配音稿。

| | 科普例：侧光为何把影子拉长 | 教程例：如何确认导出成功 |
|---|---|---|
| 第一镜 | 比较同一物体、同一地面上的两张阴影照片。请观众看影子末端。 | 先展示实际导出的文件和能打开的结果。 |
| 中间镜 | 用带地面的光路示意图解释投影；再回两张照片指出比较条件。没有角度标定就不报角度数值。 | 展示操作入口与导出选项；焦点落在下一步需要辨认的控件。 |
| 结束镜 | 回答开场问题，并说明比较假定物高、地面条件不变。 | 展示真实的文件属性或打开后的内容，而不是虚构的成功提示。 |

例如两张等高物体的不同光照照片和一张光路图，助手可把 story.json 写成下例。仅用于说明结构，不预设实际输入确有这些内容：

```json
{
  "mode": "science",
  "size": [1080, 1920],
  "fps": 25,
  "seconds": 15,
  "shots": [
    {"images": ["001", "002"], "evidence": "两图同一物体，影子末端不同", "voice": "同一个物体，为什么影子一长一短？"},
    {"images": ["003"], "evidence": "图示斜入射光线与地面的交点", "voice": "沿着物体顶端的光线看，它和地面的交点，就是影子的末端。"},
    {"images": ["001", "002"], "evidence": "回到相同地面、相同物高下的比较", "voice": "物体高度不变，光线越贴近地面，影子就越长。"}
  ]
}
```

教程用 `"mode":"tutorial"`。可不设 seconds，程序按读稿长度和看图停顿估时；指定总时长时会重新分配帧并提示不够读的镜头。双图在竖屏上下对比、横屏左右对比。同一张图上需要局部时，建议在 plan.json 给对应图层加 crop / to，不裁掉结论依赖的坐标、图例或单位。一次性修改镜头后不要再用 plan 命令覆盖手改的文件。需要持续改动时保留 story 和已定稿的 plan 两个版本。
