# 从一组图到科普片或教程

**改已有片时先分流。** 写清这次只改什么、哪些不能动（开场顺序、首次出声时间、画幅、真实附件等）。只要封面就不重剪视频；只要纯文字稿就给不含时间码和舞台说明的 TXT。用户已给终版录音时跳过选声和 TTS，直接走[实录对齐与交付](references/release.md)。未收到实录，不把按镜头估出来的字幕标作实录字幕。

## 收到图后自动执行

1. 使用 `python3 scripts/prepare.py inventory 素材目录 项目目录`。打开生成的 `contact.jpg` 看全组，再打开关键原图看图例、标签和细节。从人的目标和图的内容判断模式，不从文件名编故事。
2. **科普：回答一个为什么。** 找到图中最值得观察的区别，从现象进入；用另一幅图或局部解释机制，用可比的图或图表检验解释，最后交代适用范围。比较测量图必须保留坐标、单位、图例和必要的样本条件。示意图只是解释，不充当实测结果。涉及论文、数字或因果结论时核对原始来源；缺证据就收窄措辞。
3. **教程：教会一个可验证的动作。** 先让人看见完成后的结果，再用真实操作图按依赖顺序教学，最后显示如何判断成功。没有截图的关键步骤只作口头说明或标记补拍，不合成虚构的点击。纯程序操作、实物装配和实验流程同样适用。
4. **由执行 Skill 的助手填写**项目里的 `story.json`：选择模式、画幅、时长、每镜所用图 ID、这一镜要说明的可见事实和一句口播。一张图可用多次，也可从多图中选用少数几张。不要要求用户自己写 JSON。材料足够时直接剪；只有缺失信息会改变结论或关键操作时才提问。产物和交付模式服从用户要求。
5. 运行 `python3 scripts/prepare.py plan 项目目录`，再运行 `python3 scripts/cut.py render 项目目录/plan.json 项目目录/export`。先输出无声画面和外置字幕、旁白稿。另配声音时按用户选定的语言、读法和音色生成或录制，不把静音轨冒充配音。成片复检后再交付。细节、双图比较和样例见 [两类短片的策划示例](references/story.md)。

## 先确定观众要看见什么

- 区分“保留形式”和“替换素材”：认可旧版气泡节奏，不代表认可它画的按钮、状态栏或附件。以最后确认的分镜为准；前一版只用作指定部分的参考。
- 给出一张表：**起止秒、观众看见什么、原图与裁区、说哪一句**。分别确认开场和开始教学的时间。用户只要分镜时就停；已经确认时直接制作，不重复提问。
- 优先试剪一个决定成败的片段，例如“发出第一条指令 → 收到真实附件”。用实际投放画幅检查文件名、阅读停顿和弹出节奏。若选声音，先用含产品名、英文缩写和金额的一句测试；不要只试听平台的普通话样句。

## 建立素材与时间线

- 记录每张原图尺寸，所有裁区使用**原始像素**，而不是聊天预览的尺寸。裁掉邀请码、邮箱、预订号、二维码、密钥及无关工作路径。需要上下文时也要检查推镜的起始和过渡画面。
- **仅当素材是聊天/软件截图时**：附件保留原图里的名称、折行、省略号和图标。没有拍到的步骤可由旁白说明，不伪造输入框、扫码或连接成功。不要把已有的“取消连接”按钮当成待点击的“连接”。
- 在已有时间线里改节奏、取景、入场或文案，不把它们散落在多个不一致的脚本里。画面按帧，录音标记按原音频秒数；最终字幕用同一份映射。区分完全静音、仅效果音、禁止旁白、禁止字幕四种要求。图中的聊天原文不是字幕。未指定时，不擅自添加通知声、背景音乐或烧录字幕。
- 若用户要自然的语音，以短句和真实停顿开始；某一句装不下时先减字或延长镜头。把用于发音的写法与观众看到的写法分开。不要因改一句话就重新合成全片。

## 代码剪辑

见 [时间线格式与命令](references/editing.md)。用 `scripts/demo.py` 生成可运行的小项目；用 `scripts/cut.py` 裁切、推镜、叠加真实截图、让气泡依次入场并编码。默认产物是干净的画面母版；字幕与口播为外置文件，另行混音。需要真实点击录制而不是静帧展示时，请求操作录屏，不把推镜包装成实际点击。

## 验收与交付

- 做封面时，先写一句「观众看完能学会/理解什么」作主标题；演示案例、品牌、角色分别决定是否出现及占多大。核对用户指定的主色，缩到手机列表大小读一次主标题。案例本身就是选题时才把它做大。封面单独导出，不默认插入已确认的开头。可直接使用[封面简报与发布检查](references/release.md#封面)。

- 看**最终编码的视频**在手机大小下的开场、每个转场和结尾，确认说到按钮时按钮仍可读。检查气泡的角色方向、入场顺序和附件对应关系；查看字幕有没有遮住关键控件。测音量和是否削波不等于听过发音。
- 无声交付应当**没有音频流**，不只是把播放器静音。可选字幕不要烧在母版上。保留每句原始音频、对齐时间线的 WAV、音轨来源和逐镜文本；需要时再导出带声音的副本。
- 上传代码和公开教程模板，与交付私人截图、音轨、视频是不同的操作。公开仓库用合成测试素材；不要顺手提交包含工作凭证或真实个人数据的工程目录。
